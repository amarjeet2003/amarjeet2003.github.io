01 About

The hard parts are the fun parts.

Concurrency, throughput, fault tolerance — and making it all observable.

I'm a software engineer at iOL, where I build the systems behind a hotel-distribution analytics platform: Go microservices that match rooms across hundreds of suppliers, event-driven pipelines on Azure Service Bus and GCP Pub/Sub, and Airflow ETL that feeds PostgreSQL-backed dashboards.

I care about systems that are idempotent, recoverable and easy to reason about — dead-letter queues over silent drops, advisory locks over hoping two jobs never overlap, and a trace for every slow request.

I work AI-first: Claude Code and Cursor are part of my daily workflow, and I've shipped AI to production — from Gemini-embedding room matching to LLMs that turn messy supplier text into structured data.

03 Selected systems · in production at iOL

Problem → approach → result.

SYS-01hotel-content · Go

Room-Mapping Platform

Match the same physical room across 300+ supplier feeds — fast enough to sit in the booking path.

  • Gemini embeddings + cosine similarity with penalty rules to match rooms within and across suppliers.
  • Read path does one Redis MGET, parallel gzip decompression on a worker pool, and streams JSON back.
  • 7-day cache kept warm by daily batched refresh; v3 adds stable room clusters ranked across suppliers.

Azure → GCP Migration

Move three production services across clouds without rewriting them.

  • Built cloud-agnostic interfaces — cache (Redis | Bigtable), queue (Service Bus | Pub/Sub), storage (Blob | GCS) — picked per environment by config.
  • Cloud Run and a GCE-hosted Airflow on Cloud SQL over private IP, with secrets in Secret Manager.

SYS-03ingestion · events

Supplier Ingestion & Event Pipeline

Keep millions of rooms fresh from 7 supplier APIs without dropping a message.

  • Service Bus producer–consumer with batched sends, concurrent workers, lock renewal and dead-letter reprocessing.
  • Idempotent upserts so retries are always safe; multi-GB .jsonl.gz feeds streamed in batches to kill OOM crashes.
  • LLMs turn unstructured supplier room text into structured attributes; sources merge into 718K master hotels.

SYS-04pulse · data + api

Pulse Analytics Data Platform

Turn bookings, demand and rate-parity data into dashboards that load in seconds — not timeouts.

  • Go + Airflow pipelines: extract → object storage → COPY to staging → transform → upsert → refresh materialized views.
  • Partitioning, targeted indexes and precomputed aggregates; advisory-lock run guards and crash-resume manifests.
  • Multi-scope API cache invalidated per ETL run, moved from Redis to Bigtable; traced end-to-end with Elastic APM.
